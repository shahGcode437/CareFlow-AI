# CareFlow AI — Backend

**Phase 1 status:** foundation only (app skeleton, config, logging/request-id, health endpoint).
No appointment business logic, Excel access, agent/tool code, or authentication is implemented yet.

## Requirements

- Python 3.12+
- A virtual environment (recommended)

## Setup

```bash
cd backend
python -m venv .venv

# Windows
.venv\Scripts\activate

# macOS/Linux
source .venv/bin/activate

pip install -r requirements.txt
copy .env.example .env   # Windows
# cp .env.example .env   # macOS/Linux
```

## Run locally

```bash
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

## Verify

```bash
curl http://localhost:8000/health
```

Expected response:

```json
{
  "status": "ok",
  "app": "CareFlow AI Backend",
  "version": "0.1.0",
  "environment": "development"
}
```

Interactive API docs (auto-generated by FastAPI): http://localhost:8000/docs
